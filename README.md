# Enterprise Network Design - Cisco Packet Tracer

## Architecture
- 2 Core Switches
- 2 Distribution Switches
- 4 Access Switches

## VLANs
- VLAN 10: Administration
- VLAN 20: Salarié
- VLAN 30: Comptabilité
- VLAN 40: Serveur

## Features
- VLAN segmentation
- 802.1Q trunking
- Inter-VLAN routing
- STP redundancy
- Core / Distribution / Access architecture

## Validation
- Same VLAN communication verified
- Inter-VLAN communication verified
- Salarié ↔ Comptabilité communication verified

- Cisco Packet Tracer# enterprise-network-design-packet-tracer
